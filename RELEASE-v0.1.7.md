# v0.1.7 — подписи памяти и сети

Под MEMORY отображаются тип памяти и настроенная скорость из Windows/SMBIOS. Скорость DDR обозначается в MT/s; недоступные значения — знаком «—». Если установлены разные модули, перечисляются разные варианты. Инвентаризация выполняется один раз в фоне и не задерживает передачу кадров.

Под NETWORK отображается имя выбранного адаптера. При суммировании трафика всех адаптеров отображается «Все активные адаптеры». Подписи учитывают переключатель отображения оборудования и передаются в предпросмотр вместе с показаниями.

Блок состояния в настройках увеличен вверх на 32 пикселя, полоса прокрутки убрана, текст сделан менее ярким. Масштабирование Windows учитывается.

Скорость берётся из ConfiguredClockSpeed, а не номинального Speed: [Microsoft WMI](https://learn.microsoft.com/en-us/windows/win32/cimwin32prov/win32-physicalmemory), единицы MT/s соответствуют полю SMBIOS Configured Memory Speed.

Проверка реального экрана после установки остаётся за пользователем. USB-протокол и драйвер не изменены.
